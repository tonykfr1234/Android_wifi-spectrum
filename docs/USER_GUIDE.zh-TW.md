# 使用指南

## 第一次開啟

1. App 會先說明為什麼需要權限。按「允許權限並開始掃描」。
2. 系統詢問位置時選**精確位置**、**使用 App 時允許**。只給大概位置的話，Android 不會提供 Wi-Fi 掃描結果。
3. Android 13 以上還會詢問「附近的 Wi-Fi 裝置」，請允許。
4. 沒有跳出詢問（之前選過「不要再詢問」）時，按「到系統設定開啟權限」。
5. 只想先看看介面，可以按「先看示範模式」。

## 五個分頁

| 分頁 | 用途 |
| --- | --- |
| 網路 | 最上方是目前連線（速度、IP、MLO 使用中連結），下方是所有基地台 |
| 頻譜 | 每台基地台一條曲線，高度是訊號強度、寬度是頻寬 |
| 趨勢 | 最近 60 次掃描的訊號變化，找出訊號不穩的基地台 |
| 評分 | 每個頻道的擁擠程度與推薦頻道 |
| MLO | Wi-Fi 7 路由器的多條連結合併顯示 |

## 上方按鈕

| 按鈕 | 功能 |
| --- | --- |
| 重新整理 | 立即掃描一次 |
| 暫停／播放 | 停止或恢復自動掃描 |
| ⋮ 選單 | 掃描間隔、示範模式切換、隱私權政策、關於 |

掃描間隔預設 30 秒。Android 限制前景 App 每 2 分鐘最多掃描 4 次，設得更短會出現「節流」提示並顯示上次的結果。開發時可以到「開發人員選項」關閉「Wi-Fi 掃描節流」。

## 網路清單

- 左邊數字是訊號（dBm），越接近 0 越強：-50 以上極佳，-60 良好，-70 普通，-80 以下很弱。
- 標籤依序是：頻段與主頻道、頻寬、Wi-Fi 世代、加密方式、MLO 連結編號。
- 紅色加密標籤代表開放網路、WEP 或只有 WPA，安全性不足。
- 右邊的距離是無遮蔽環境的估算，穿牆後實際距離會更近。
- 搜尋框可以找 SSID 或 BSSID。下方篩選可以切換頻段、最小頻寬（≥40／80／160／320）、只看 Wi-Fi 7、隱藏網路，以及排序方式。
- 點任一台基地台進入詳細資料：佔用範圍、涵蓋頻道、是否 PSC／DFS、原始加密字串、MLO 各連結。

## 頻譜圖

- 2.4 GHz 只有 1、6、11 三個互不重疊的頻道。曲線底部互相蓋住就代表會干擾。
- 5 GHz 和 6 GHz 預設整段總覽。按「放大」可以左右滑動看細節。
- 粗線是你目前連線的基地台；連線的是 Wi-Fi 7 路由器時，它在其他頻段的連結也會加粗。
- 6 GHz 的紫色頻道號碼是 PSC 頻道。

## 頻道評分

- 分數依附近基地台的訊號強度與重疊頻寬計算，越強、重疊越多扣越多。
- 2.4 GHz 只推薦 1、6、11。
- 5 GHz 干擾相同時優先推薦 36–48、149–165。52–144 是 DFS 頻道（標「D」），偵測到雷達時路由器必須暫停並換頻道；只有在明顯比較安靜時才會推薦。
- 6 GHz 優先推薦 PSC 頻道（標「P」），手機才會快速找到你的網路。

## MLO

- 需要 Wi-Fi 7 路由器，而且手機要是 Android 13 以上、支援 Wi-Fi 7。
- 「目前連線的 MLD」顯示手機實際使用中的連結；各條連結的訊號需要 Android 14 以上。
- 「已宣告，這次沒掃到」代表路由器宣告了這條連結，但這次掃描沒收到它的訊號，常見於 6 GHz 穿牆後太弱。

## 常見狀況

| 狀況 | 原因與處理 |
| --- | --- |
| 6 GHz 沒有任何基地台 | 手機不支援 Wi-Fi 6E，或附近沒有 6 GHz 路由器 |
| 沒有 320 MHz 或 MLO | 手機未支援 Wi-Fi 7、Android 版本低於 13，或路由器未開啟 |
| Wi-Fi 標準顯示「未知」 | Android 10 以下不回報 |
| 出現「定位服務已關閉」 | 到快速設定開啟定位；Android 規定定位開啟才能取得掃描結果 |
| 連線名稱顯示需要權限 | 沒有授予精確位置 |
